# Changelog

All notable changes to this repository are documented here.

## [2.0.0] - 2026-11-27

### Changed

- Expanded the skill from UI-only guidance into an end-to-end application-development workflow while preserving the existing skill name and install path.
- Consolidated repeated setup, handoff, browser, lessons-learned, and verification guidance into one canonical lifecycle with focused references.
- Made credible existing-system research a required gate before greenfield scaffolding.
- Reduced `AGENTS.md` to repository-specific invariants and validation commands.

### Added

- Evidence-based portable design guide and proportional quality gates.
- Verified public-source audit distinguishing Impeccable from Unslop.
- Cross-device project bootstrap helper and project brief template.
- Reviewed routing for Unslop, Awesome Design MD, Impeccable, Taste Skill, Vercel guidelines, Playwright MCP, Transitions, and BoardUI.
- Idempotent project-level `AGENTS.md` references with a check mode suitable for local setup or CI.
- Validation for the research, authorization, and canonical-guide invariants.

## [1.1.0] - 2026-11-22

### Added

- Chat-to-Codex project handoff standard and reusable handoff template.
- Minimum project setup and security/privacy checklists.
- New-project and existing-project handoff examples.
- Cross-platform install/update helpers.
- Deterministic repository validation and GitHub Actions automation.
- Contribution guidance, repository scope, and source-review metadata.

### Changed

- Clarified the boundary between the UI skill and the broader supporting standards bundle.
- Refreshed the external component-source review notes.

## [1.0.0] - 2026-11-21

### Added

- Initial workflow-first application UI skill.
- Component-source, verification, and lessons-learned references.
- Global software-design and Playwright MCP browser-testing standards.
